# MathArtLab

PythonとMatplotlibを使用して、数学的な美しいアトラクター、フラクタル、および幾何学曲線をプログラムで自動生成するコレクションプロジェクトです。

## 収録されているアート一覧 (全12種類)

1. **ドラゴン曲線 (`dragon-curve.py`)**
   - 世代数や進行順序、ターン、密度に基づく多様なルールでドラゴン曲線を生成します。
2. **ゴールドバッハ彗星 (`goldbach-comet.py`)**
   - ゴールドバッハ予想に関連する素数ペアの分布を散布図として可視化します。
3. **クリフォードのアトラクター (`clifford-attractor.py`)**
   - カオス理論に基づくクリフォードのアトラクターの軌跡を描画します。
4. **ローレンツのアトラクター (`lorenz-attractor.py`)**
   - 非線形微分方程式から導かれるローレンツ・アトラクターの立体的な軌跡を可視化します。
5. **バラ曲線 (`rose-curve.py`)**
   - 極方程式で表される幾何学的なバラ曲線を綺麗に描画・重ね合わせます。
6. **ジュリア集合 (`julia-set.py`)**
   - 複素力学系に基づく美しいジュリア集合のフラクタル図形を描画します。
7. **マンデルブロ集合 (`mandelbrot-set.py`)**
   - 複素力学系に基づくマンデルブロ集合のフラクタル図形を描画します。
8. **リサージュ図形 (`lissajous-curve.py`)**
   - 直交する正弦波の合成によって描かれる幾何学模様を描画します。
9. **エノン・アトラクター (`henon-attractor.py`)**
   - 2次元のカオス力学系に基づくエノン・アトラクターを描画します。
10. **レスラーのアトラクター (`rossler-attractor.py`)**
    - 3次元の連続力学系に基づくらせん状のレスラー・アトラクターを描画します。
11. **ド・ジョン・アトラクター (`dejong-attractor.py`)**
    - 三角関数を組み合わせた2次元マップによるド・ジョン・アトラクターを描画します。
12. **相沢のアトラクター (`aizawa-attractor.py`)**
    - 3次元空間内で球状にねじれながら渦巻く相沢のアトラクターを描画します。

## 動作環境と必要ライブラリ

以下のPythonライブラリが必要です。あらかじめインストールしてお使いください。

- Python 3.x
- NumPy
- Matplotlib

インストールコマンド:
```bash
pip install numpy matplotlib
```

## 使い方

### 1. ランチャーからの実行（推奨）
プロジェクトルートにあるランチャーを使うと、対話メニュー形式で簡単に実行できます。

- **Windowsの場合**: 
  **`run.bat`** をダブルクリックして起動します。
- **Mac / Linuxの場合**: 
  初めて実行する際、ターミナルで実行権限を付与してから起動します。
  ```bash
  chmod +x run.sh
  ./run.sh
  ```
メニューが表示されたら、生成したいアートの番号（1〜12）を選択してください。

### 2. 個別の直接実行
ターミナルやコマンドプロンプトから各プログラムを直接実行することも可能です。

```bash
# Windows
py dragon-curve.py

# Mac / Linux
python3 dragon-curve.py
```

## 主な機能と特徴

- **動的パラメータ入力**: 
  プログラムを実行すると、ターミナル上で「点の太さ」や「計算回数・シミュレーションステップ数」をその場で指定できます。何も入力せずにEnterキーを押すと、デフォルト値が適用されます。
- **背景モードの選択（ダーク・ライト・透過）**: 
  生成時に、背景を「ダーク（黒背景）」「ライト（白背景）」「透過（透明背景）」の中から必要なものを個別に指定するか、あるいはすべて一括して生成するかを選択できます。
- **自動フォルダクリーンアップ**: 
  画像を出力する際、指定された専用フォルダ内の古い生成物が自動で一括削除され、今回新しく設定・生成されたファイルのみが常にクリーンな状態で保持されます。
- **リアルタイム進捗プログレスバー**: 
  重い計算や複数パターンの画像生成中、ターミナル上に現在の進行度をリアルタイムの進捗バーとパーセンテージで表示します。
- **Git管理の最適化**: 
  生成された画像ファイルは `.gitignore` により `outputs/` フォルダごと自動的にバージョン管理の対象外となるため、リポジトリが画像で肥大化するのを防ぎます。
