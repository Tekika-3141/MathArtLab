# MathArtLab

PythonとMatplotlibを使用して、数学的な美しいアトラクター、フラクタル、および幾何学曲線をプログラムで自動生成するコレクションプロジェクトです。すべての生成画像は、高解像度（600 DPI）でダークテーマとライトテーマの両方が自動出力され、`outputs/` フォルダ内に綺麗に整理されます。また、実行時にはターミナル上に進捗プログレスバーが表示されます。

## 収録されているアート一覧

1. **ドラゴン曲線 (`dragon-curve.py`)**
   - 世代数（折れ曲がり回数）や進行順序、ターン、密度に基づく多様なルールでドラゴン曲線を生成します。
2. **ゴールドバッハ彗星 (`goldbach-comet.py`)**
   - ゴールドバッハ予想に関連する素数ペアの分布を散布図として可視化します。
3. **クリフォードのアトラクター (`clifford-attractor.py`)**
   - カオス理論に基づくクリフォードのアトラクターの軌跡を描画します。
4. **ローレンツのアトラクター (`lorenz-attractor.py`)**
   - 非線形微分方程式から導かれるローレンツ・アトラクターの立体的な軌跡を可視化します。
5. **バラ曲線 (`rose-curve.py`)**
   - 極方程式で表される幾何学的なバラ曲線を綺麗に描画・重ね合わせます。
6. **ジュリア集合 (`julia-set.py`)**
   - 複素力学系に基づく美しいジュリア集合のフラクタル図形を描画します。
7. **マンデルブロ集合 (`mandelbrot-set.py`)**
   - 複素力学系に基づくフラクタル図形の王道であるマンデルブロ集合を描画します。
8. **リサージュ図形 (`lissajous-curve.py`)**
   - 直交する正弦波の合成によって描かれる美しい幾何学的な図形を描画します。

## 🚀 使い方

### 1. バッチファイルから起動する場合（おすすめ）
同梱されているランチャーバッチファイルをダブルクリックするか、ターミナルから実行します。対話形式でパラメータの変更も可能です。
```cmd
run.bat
```

### 2. 個別にPythonスクリプトを実行する場合
特定のプログラムを直接実行したい場合は、ターミナルから以下のように実行します。
```bash
python dragon-curve.py
```

---

## 🎨 出力仕様・新機能

- **プログレスバー**: 実行中、ターミナルにリアルタイムで進捗状況（ゲージとパーセンテージ）が表示されます。
- **保存先**: `outputs/{アート名}/` フォルダ内に自動作成されます。
- **画像フォーマット**: PNG（600 DPIの高解像度）
- **テーマ**: ダーク背景（`_dark.png`）とライト背景（`_light.png`）をペアで自動生成します。

## 動作環境・必要ライブラリ

以下のPythonライブラリが必要です。あらかじめインストールしてお使いください。

- Python 3.x
- NumPy
- Matplotlib

インストールコマンド:
```bash
pip install numpy matplotlib
```
